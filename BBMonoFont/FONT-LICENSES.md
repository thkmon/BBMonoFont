## Modified font names

파생 결과의 사용자 표시 이름은 `BB Mono I`와 `BB Mono S`입니다. Reserved Font
Name인 `Plex`와 `Source`는 패밀리명, 전체 이름, PostScript 이름에 사용하지
않습니다. 원본 이름은 출처와 설계를 설명하는 문서 및 description 메타데이터에만
표시됩니다.

원본 폰트와 파생 폰트를 재배포할 때는 해당 OFL 원문과 저작권 고지를 함께
제공해야 합니다. OFL에 관한 공식 설명은 <https://openfontlicense.org/>에서
확인할 수 있습니다.
